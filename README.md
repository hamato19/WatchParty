# 🎬 WatchParty

تطبيق Android للمشاهدة الجماعية يتيح للمستخدمين مزامنة تشغيل الفيديو والدردشة معاً في الوقت الفعلي.

## 🚀 مميزات المشروع
* **مزامنة التشغيل:** التحكم في تشغيل وإيقاف الفيديو لجميع المشاركين في الغرفة.
* **دردشة فورية:** إرسال واستقبال الرسائل النصية بالتزامن مع العرض.
* **بناء تلقائي (CI/CD):** إعدادات جاهزة عبر GitHub Actions لبناء ملفات الـ APK تلقائياً.
